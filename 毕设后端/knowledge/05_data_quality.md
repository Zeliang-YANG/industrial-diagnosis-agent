# 工业时序数据质量与诊断边界

## 采集空档

首条和末条遥测只定义观测边界，不代表中间连续采集。相邻样本超过系统允许间隔时应切分观测段，报告分段数量、连续覆盖时长和最大空档。空档期间的产量、状态和停机原因不可由两端样本直接补齐。

## 状态事件重叠

同一设备在同一时间出现两个互斥状态，说明事件切分、补全或时钟存在问题。发生重叠时，不应把重叠时长重复计入 KPI。先核对事件 ID、开始结束时间、采集进程重启点和设备时钟，再决定修复策略。

## 未闭合事件

开放事件可以在实时查询中暂时截止到查询时刻，但必须标记为未闭合。服务异常退出后重启，应根据后续状态和最后有效遥测确定边界；不能简单把整个停机间隔算作上一状态的持续时间。

## 累计计数器重置

累计产量下降可能来自设备重启、班次清零、溢出或数据源替换。诊断时累计相邻非负增量，并标记重置位置。若采集中断跨越重置点，无法仅凭现有样本恢复真实产量。

## 证据等级

- 直接观测：数据库数值、状态事件、报警码、控制器记录。
- 关联线索：时间先后、指标分解、多个信号共同变化。
- 知识假设：知识库给出的常见原因和检查方向。
- 已确认根因：现场检查、维修记录或可重复实验支持的结论。

Agent 应明确区分这些等级，不得把知识假设写成直接观测。
